# The paper's integration points

This repository produces everything a LaTeX paper needs. A draft is at [`draft/paper.tex`](draft/paper.tex), and `make paper` compiles it against the current results. These are the integration points it uses, and nothing else. Each result in the draft is marked `\claim{<key>}`, naming its row in `CLAIMS.md` and giving the Lean table (`tables/lean.tex`) its section column; `tests/test_claim_keys.py` checks every key resolves.

## Numbers

```latex
\input{numbers.tex}
```

One command per quoted value (`\smKinetic`, `\smThreshold`, `\genCountThree`, `\smCutoffLow`, ...), generated by `igc.latex` from `igc.emit.macros()`, which reads `results/*.json`. The same names fill the repository's own documents, so the paper and the README cannot quote different numbers. A regenerated result changes the paper's numbers without touching its source. Every name is listed, typeset, in `build/latex/gallery.tex`.

## Tables

```latex
\input{tables/conditions.tex}   % table*  (paragraph columns)
\input{tables/species.tex}      % table*
\input{tables/count.tex}        % table*  (the Standard Model, species by species)
\input{tables/neutrinos.tex}    % table
\input{tables/magnitude.tex}    % table
\input{tables/lean.tex}         % table*  (each result's key, section and Lean statements)
```

Booktabs tabulars, read only from `results/`, `data/` and the claims registry. Each file's first line names the float it needs; the float and its caption are the paper's.

## Figures

```latex
\includegraphics[width=\columnwidth]{generations.pdf}
\includegraphics[width=\columnwidth]{criterion.pdf}
```

One column wide, read only from `results/` (`experiments/figures.py`). PNG copies are committed for browsing.

## References

```latex
\bibliographystyle{apsrev4-2}   % implied by revtex4-2
\bibliography{refs}
```

`refs.bib`, generated from `data/references.yaml`, so the paper and the documents cite identically.

## Building and testing the feed

```
make latex figures       # writes build/latex/ and build/figures/
make paper-test          # compiles test/minimal.tex against them
make paper               # compiles draft/paper.tex against them
```

`test/minimal.tex` uses the paper's class (`revtex4-2`, `aps,prd,twocolumn`) with every package the paper will use. It typesets every number, places every table in its float and both figures, runs every reference through bibtex, and includes a paragraph-column table. It proves the feed compiles; it is not a draft. A clean compile does not prove a table fits, so every page of its PDF is rendered and read.

**One package is left out on purpose.** Under `revtex4-2` in this toolchain, the `array` package breaks every paragraph (`p{}`) column with "Extra \or". So does `siunitx`, which loads `array`. `revtex4-2`'s own tabular handles `p{}` and `@{}` columns, so neither package is used, and numbers are set as plain text.
